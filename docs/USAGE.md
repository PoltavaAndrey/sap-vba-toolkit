# Инструкция по установке и использованию

## 1. Подготовка SAP GUI

1. Откройте **SAP Logon** -> **Параметры (Options)** -> **Скриптинг
   (Accessibility & Scripting -> Scripting)**.
2. Установите флажок **"Включить скриптинг" (Enable scripting)**, снимите
   флажки предупреждений (по желанию, для тихой работы).
3. Уточните у администратора SAP, что на сервере параметр
   `sapgui/user_scripting` установлен в `TRUE` (транзакция `RZ11`) - без
   этого скриптинг не заработает даже с включенными настройками клиента.
4. Войдите в SAP GUI в одну из сессий (макрос подключается к уже открытой
   и залогиненной сессии, а не логинится сам).

## 2. Импорт кода в книгу Excel

1. Откройте книгу Excel, из которой будет запускаться макрос.
2. Откройте редактор VBA (`Alt+F11`).
3. Через `Файл -> Импорт файла...` импортируйте по очереди:
   - `src/Interfaces/ILogger.cls`
   - все файлы из `src/Classes/`
   - все файлы из `src/Modules/`
4. Сохраните книгу как `.xlsm` (с поддержкой макросов).

> Импорт можно частично автоматизировать через `Application.VBE`, но из
> соображений безопасности такой скрипт не включен в репозиторий - многие
> организации блокируют программный доступ к VBE (Trust access to the VBA
> project object model).

## 3. Настройка путей и параметров

Откройте `modConfig.bas` и задайте:

```vba
Public Const DEFAULT_INPUT_FILE As String = "C:\Data\input.xlsx"
Public Const DEFAULT_OUTPUT_FILE As String = "C:\Data\output.xlsx"
```

Формат входного файла по умолчанию (лист `Лист1`, заголовки в первой
строке) ожидается такой, какой читает `clsExcelReader.ReadSheetAsRecords`.
Пример:

| Материал |
|----------|
| 1000123  |
| 1000456  |

## 4. Проверка соединения с SAP

В редакторе VBA выполните (`F5` с курсором внутри процедуры):

```vba
modMain.TestSapConnection
```

Появится сообщение об успехе/неуспехе подключения. При ошибке -
подробности смотрите в файле лога (папка `Logs` рядом с книгой Excel).

## 5. Адаптация бизнес-логики под вашу транзакцию

`clsAppController.ProcessSingleRecord` в текущем виде - это шаблон под
транзакцию `ME21N` (создание заказа на закупку). Чтобы адаптировать под
свою транзакцию:

1. Откройте нужную транзакцию в SAP GUI.
2. Включите **"Помощь по сценарию" / Scripting Recorder** или наведите
   курсор на поле и посмотрите его ID в статусной строке
   (обычно включается через `Ctrl` + правый клик -> "Показать ID
   элемента" / Status Bar -> Script Recording and Playback).
3. Замените в `ProcessSingleRecord` код транзакции (`StartTransaction`) и
   ID полей (`SetText`, `ClickButton` и т.д.) на реальные значения из
   вашей транзакции.
4. При необходимости добавьте обработку всплывающих окон/предупреждений
   через `sapSession.ControlExists(...)` перед обращением к ним.

## 6. Запуск полного сценария

```vba
modMain.RunDefault
' или с явными путями:
modMain.RunScenario "C:\Data\input.xlsx", "C:\Data\output.xlsx"
```

По завершении в папке `Logs` появится файл лога за текущую дату, а по
указанному пути - файл отчета Excel со статусом обработки каждой строки.

## 7. Частые проблемы

| Симптом                                             | Возможная причина                                                        |
|------------------------------------------------------|---------------------------------------------------------------------------|
| `connector.Connect()` возвращает `False`             | SAP Logon не запущен, скриптинг выключен в клиенте или на сервере          |
| Ошибка "Object variable not set" при `FindById`      | Неверный ID элемента (изменился после обновления SAP, транзакция другая)  |
| Второй экземпляр Excel "зависает" в диспетчере задач | `CloseFile`/`Class_Terminate` не были вызваны из-за необработанной ошибки  |
| Макросы заблокированы при открытии файла             | В настройках Excel отключено выполнение макросов - включите Trust Center  |
